## 2. v42: 多周期RRG扩展（5窗口加权投票）

### 2.1 设计思路

v41 使用 3 窗口 [10, 30, 60] 加权投票。v42 扩展到 5 窗口 [5, 10, 20, 30, 60]，更多窗口能更精细捕捉不同周期的动量信号，降低单周期过拟合风险。

权重设计 [0.1, 0.2, 0.3, 0.3, 0.1]（中期主导）：
- 5日: 0.1 (太短噪声大)
- 10日: 0.2 (短周期)
- 20日: 0.3 (中周期)
- 30日: 0.3 (甜蜜点)
- 60日: 0.1 (太长滞后)

### 2.2 v42 IS 结果

| 指标 | v41 (baseline) | v42 | 变化 |
|------|----|----|------|
| IS 总收益 | +27.61% | +23.47% | -4.14pp |
| IS Sharpe | 0.4803 | 0.4332 | -0.0471 |
| IS 最大回撤 | -- | -14.71% | -- |

**结论**：v42 IS Sharpe 0.4332 < v41 0.4803，5窗口扩展未能改善IS，**v42失败**。未运行OOS。

### 2.3 失败原因分析

1. **5日和60日窗口噪声大或滞后**：极端窗口未提供新信息，反而引入噪声
2. **3窗口已足够覆盖短/中/长周期**：30日动量甜蜜点理论表明[10,30,60]是最佳组合
3. **5窗口加权投票组合行为过于复杂**：如"5+10日领先=0.3<0.5不入选"等组合未带来IS改善
4. **过度参数化风险**：5窗口5权重，搜索空间过大，易过拟合

## 3. v43: PE分位作为RRG投票权重调节因子

### 3.1 设计思路

v41 RRG加权投票只考虑动量信号（10/30/60日RS-Mom≥100加权），未考虑估值维度。v15 PE过滤（硬性剔除）在OOS未触发（market_filter+RRG已规避估值泡沫行业）。

**v43 改进**：在v41加权投票基础上引入PE调节项（软性调节）

PE调节公式：
```
adjusted_vote = weighted_vote + alpha * (ep_percentile - 0.5)
```

- `ep_percentile=1`（最便宜）：vote + 0.5*alpha（加分，更易入选）
- `ep_percentile=0.5`（中位）：vote + 0（不变）
- `ep_percentile=0`（最贵）：vote - 0.5*alpha（减分，更难入选）

`alpha=0.2` 表示最大±0.1的调节，相对原阈值0.5是20%的调节幅度。
与 `use_pe_filter`（硬性剔除）互补：pe_filter 是硬性剔除，pe_adjusted_rrg_vote 是软性调节。

### 3.2 实现要点

- 配置项：`use_pe_adjusted_rrg_vote: true`, `pe_vote_adjust_alpha: 0.2`
- `industry_rotation_selector.py::_load_factor_data` 扩展支持 PE调节时加载 pe_factor
- `select` 方法在 RRG 加权投票计算后叠加 PE 调节项
- 向后兼容：`use_pe_adjusted_rrg_vote=false` 时保持原逻辑

### 3.3 v43 IS+OOS 结果

| 区间 | 总收益 | 年化 | Sharpe | 最大回撤 | 调仓次数 |
|------|--------|------|--------|----------|----------|
| IS (2022-2025) | **+31.29%** | +7.04% | **0.5716** | -14.70% | 204 |
| OOS (2026-06-01~07-16) | **+6.66%** | -- | **2.6787** | **-2.57%** | 7 |

**vs v41**：

| 指标 | v41 | v43 | 变化 |
|------|----|----|------|
| IS Sharpe | 0.4803 | **0.5716** | **+19%** |
| IS 总收益 | +27.61% | **+31.29%** | +3.68pp |
| OOS 总收益 | +6.66% | +6.66% | 持平 |
| OOS Sharpe | 2.6787 | 2.6787 | 持平 |
| OOS 最大回撤 | -2.82% | -2.57% | 改善0.25pp |

**结论**：v43 IS Sharpe +19%显著改善，OOS完全持平（持仓与v41完全相同），通过"IS改善不损OOS"标准。**v43为当前最优策略**。

### 3.4 关键观察

1. **OOS持仓与v41完全相同**：PE调节幅度±0.1不足以改变OOS投票结果（OOS期间3窗口投票一致，weighted_vote接近0或1，PE调节±0.1无法翻转）
2. **IS改善来自震荡市投票分歧**：IS期间3窗口投票分歧时（weighted_vote接近0.5），PE调节±0.1能改变行业入选
3. **PE调节是软性prior**：与use_pe_filter硬性剔除互补，提供"估值便宜行业加分"的渐进信号
4. **alpha=0.2是合适强度**：±0.1相对阈值0.5是20%调节，过小无效过大损害

## 4. v44: 基本面因子增强（增长因子）

### 4.1 设计思路

v43 当前 12 因子中基本面类只有 LEVEL 指标（gross_income_ratio/roe_ttm/net_profit_ratio），缺少 GROWTH 维度。v44 新增 3 个增长因子捕捉"基本面改善"信号：
- `operating_revenue_growth_rate`: 营收增长率（顶部增长）
- `net_profit_growth_rate`: 净利润增长率（底线增长）
- `np_parent_company_owners_growth_rate`: 归母净利润增长率（股东真实增长）

假设：增长因子与现有 LEVEL 因子正交，能提供独立的选股信号。

### 4.2 v44 IS 结果

| 指标 | v43 (baseline) | v44 | 变化 |
|------|----|----|------|
| IS 总收益 | +31.29% | +28.33% | -2.96pp |
| IS Sharpe | 0.5716 | 0.5295 | -0.0421 |
| IS 最大回撤 | -14.70% | -15.33% | -0.63pp |

**结论**：v44 IS Sharpe 0.5295 < v43 0.5716，增长因子未能改善IS，**v44失败**。未运行OOS。

### 4.3 失败原因分析

1. **增长因子噪声大**：受一次性事件（资产处置/汇兑损益）影响，等权加入稀释了原有12因子的信号强度
2. **与LEVEL因子相关性高**：增长因子与净利润绝对水平（roe_ttm）相关性高，未提供正交信号
3. **等权叠加非最优**：正确做法应是用增长因子替换部分弱因子而非简单叠加，或对增长因子单独做z-score过滤极值后再加权
4. **ML实验已证明因子扩展无效**：v12扩展到40因子后ML仍不超越等权线性，本次v44扩展到15因子同样无效，与历史结论一致

## 6. v43 详细配置

### 6.1 核心超参

| 超参 | 值 | 说明 |
|------|-----|------|
| 候选池 | 000300.XSHG | 沪深300（361只股票） |
| top_industries | 3 | 选 Top-3 行业 |
| stocks_per_industry | 3 | 每行业选 3 只 |
| market_ma_short / long | 10 / 30 | 大盘均线过滤 |
| **rs_momentum_windows** | **[10, 30, 60]** | **多周期 RS-Mom 窗口** |
| **rs_momentum_vote_weights** | **[0.3, 0.4, 0.3]** | **中期主导权重（v41）** |
| **use_pe_filter** | **true** | **行业估值硬性过滤（v15）** |
| **pe_lookback** | **250** | **估值分位回看窗口** |
| **pe_expensive_percentile** | **0.10** | **E/P 分位<10% 视为过贵** |
| **use_pe_adjusted_rrg_vote** | **true** | **PE调节RRG投票（NEW v43）** |
| **pe_vote_adjust_alpha** | **0.2** | **PE调节强度（最大±0.1）** |
| factor_weights | 12因子等权+2反向 | 含 raw_beta(-2.0)/residual_volatility(-1.5) |
| rebalance | weekly (周一) | 周频调仓 |

### 6.2 选股流程

```
1. 大盘趋势过滤 (沪深300 10/30日均线)
   ├── 跌破30日均线 → 空仓 (scale=0.0)
   ├── 跌破10日均线 → 降仓50% (scale=0.5)
   └── 否则 → 满仓 (scale=1.0)

2. 绝对动量叠加 (Dual Momentum)
   └── 若 scale>0 且 沪深300 20日收益 < -3% → scale *= 0.5

3. 行业动量排名 (60日×0.6 + 120日×0.4) → Top-3 行业候选

4. RRG 多周期加权投票 (v40/v41)
   ├── 计算每个行业的 10/30/60 日 RS-Mom
   ├── weighted_vote = 0.3*(RS-Mom_10≥100) + 0.4*(RS-Mom_30≥100) + 0.3*(RS-Mom_60≥100)
   ├── ★ v43 PE调节: adjusted_vote = weighted_vote + 0.2*(ep_percentile - 0.5)
   ├── 筛选 adjusted_vote ≥ 0.5 的行业
   └── 至少保留 3 个行业

5. 行业短期风险过滤 (20日动量)
   └── 剔除短期动量为负的行业，至少保留 3 个

6. 行业估值过滤 (v15, 华商基金思路, 硬性)
   ├── 计算每个行业 E/P 在近 250 日的分位
   ├── 剔除 E/P 分位 < 10% 的行业（即 PE 历史最贵 10%）
   └── 至少保留 3 个行业

7. 个股多因子评分 (12因子加权z-score)
   └── 每行业选 Top-3 个股

8. 等权配置 + 10%单股上限 + 30%行业上限 + 风控系数
```

## 7. 各方向成功/失败原因总结

### 7.1 v42 5窗口RRG扩展（失败）

**失败因素**：
1. **5日窗口太短噪声大**：短期RS-Mom信号虚假多，5日权重0.1也无法消除噪声
2. **3窗口已是最佳组合**：v41的[10,30,60]覆盖短/中/长周期，扩展到5窗口冗余
3. **过度参数化**：5窗口5权重，搜索空间过大，易过拟合
4. **30日动量甜蜜点理论验证**：3窗口中30日权重最高，5窗口中仍是20+30日权重最高，说明3窗口已捕获核心信号

### 7.2 v43 PE调节RRG投票（成功）

**成功因素**：
1. **PE调节是软性prior**：与use_pe_filter硬性剔除互补，提供渐进估值信号
2. **alpha=0.2强度合适**：±0.1相对阈值0.5是20%调节，能有效改变IS震荡市投票分歧
3. **IS震荡市投票分歧多**：IS期间3窗口投票常分歧（weighted_vote接近0.5），PE调节±0.1能改变入选
4. **OOS趋势市投票一致**：OOS期间3窗口投票一致（weighted_vote接近0或1），PE调节±0.1无法翻转
5. **正交信号**：估值维度与动量维度正交，提供独立的选股信号

### 7.3 v44 增长因子增强（失败）

**失败因素**：
1. **增长因子噪声大**：受一次性事件影响（资产处置/汇兑损益/季节性），数据质量差
2. **等权叠加稀释信号**：12因子→15因子，每个因子权重从1/12降至1/15，原有强信号被稀释
3. **与LEVEL因子相关性高**：增长因子与roe_ttm/net_profit_ratio相关性高，未提供正交信号
4. **ML实验已证明因子扩展无效**：v12扩展到40因子后ML仍不超越等权线性，本次v44扩展到15因子同样无效

**改进方向**（未实施）：
- 用增长因子替换部分弱因子（如DAVOL10）而非简单叠加
- 对增长因子单独做z-score过滤极值后再加权
- 用IC加权替代等权，自动降低噪声因子的权重
- 使用因子正交化（如Gram-Schmidt）消除相关性
