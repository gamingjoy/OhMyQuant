## 1. 策略概述

### 1.1 核心思路

行业轮动策略：在强势行业中选强势个股，利用聚宽260因子做个股层多因子选股，并通过 RRG相对强度动量+行业短期风险过滤+绝对动量三重防御规避高风险板块。

- **行业层**: 60+120日动量排名选Top-5 → RRG(RS-Ratio 220日 + RS-Momentum 30日)重选领先象限 → 20日短期风险过滤（至少保留3个）
- **个股层**: 12因子加权z-score复合评分（含2个反向BARRA风险因子），每行业选Top-2个股
- **风控层**: 大盘趋势过滤（跌破20日均线空仓，跌破5日均线降仓50%）+ 绝对动量（20日收益<-3%降仓50%）+ regime_adaptive风控
- **调仓**: 周频调仓（每周一），cost_benefit调仓模型

### 1.2 v9 相对 v8 的改进

v9 在 v8 基础上新增 **RRG（Relative Rotation Graph）相对强度动量** 行业选择层：

1. **RRG 框架（2026 量化轮动策略报告）**：
   - RS-Ratio = 行业均价 / 沪深300 close 的 220 日标准化值（>100 表示长期跑赢大盘）
   - RS-Momentum = RS-Ratio 的 30 日动量（>100 表示相对强度在加速）
   - 行业选择：先按 RS-Ratio 取候选，再剔除 RS-Momentum<100 的疲软象限
   - RS-Momentum 是先行指标，能在行业绝对动量仍正但相对强度已转弱时提前剔除

2. **30日窗口（vs 研报60日）的关键改进**：
   - 研报推荐 60 日 RS-Momentum，但在 v9 OOS 中无法识别建筑材料短期转弱（60日RS-Mom=108.33>100）
   - 30 日窗口更敏感：6/22 建筑材料 RS-Mom=97.34<100，被成功剔除，换成银行
   - 避免了7月建筑材料下跌，OOS 超额收益从 +0.29% 提升至 +1.50%

3. **保留 v8 所有特性**：12因子选股、行业短期风险过滤、绝对动量、大盘过滤

### 1.3 v8 OOS 亏损根源分析

v8 OOS 6/22 调仓选了建筑材料+电子+通信（60%仓位），7月建筑材料大跌导致策略亏损。
- 建筑材料 60/120日绝对动量仍正 → 入选
- 建筑材料 60日 RS-Mom=108.33 > 100 → RRG(60日) 也认为它是领先行业
- **建筑材料 30日 RS-Mom=97.34 < 100 → RRG(30日) 识别转弱，剔除**

v9 30日窗口成功识别建筑材料相对强度已转弱，将其替换为银行，避免7月亏损。

### 1.4 选股流程

```
1. 大盘趋势过滤 (沪深300 5/20日均线)
   ├── 跌破20日均线 → 空仓 (scale=0.0)
   ├── 跌破5日均线 → 降仓50% (scale=0.5)
   └── 否则 → 满仓 (scale=1.0)

2. 绝对动量叠加 (Dual Momentum)
   ├── 若 scale>0 且 沪深300 20日收益 < -3% → scale *= 0.5
   └── 否则 → scale 不变

3. 行业动量排名 (60日×0.6 + 120日×0.4)
   └── 选 Top-5 行业（候选）

4. RRG 行业重选 (NEW in v9, RS-Ratio 220日 + RS-Momentum 30日)
   ├── 按 RS-Ratio 取候选池 top_industries×2
   ├── 筛选 RS-Momentum >= 100 的领先象限
   ├── 至少保留 rrg_min_industries 个，不足时按 RS-Ratio 排名补充
   └── 替换原 Top-5（剔除相对强度转弱的，新增相对强度领先的）

5. 行业短期风险过滤 (20日动量)
   ├── 剔除短期动量为负的行业 (规避下跌板块)
   └── 至少保留 3 个行业

6. 个股多因子评分 (12因子加权z-score，含2个反向风险因子)
   ├── 动量类(正): Price1M, Price3M, ROC20
   ├── 成交量类(正): DAVOL10, money_flow_20
   ├── 质量类(正): gross_income_ratio, roe_ttm, net_profit_ratio
   ├── 价值类(正): earnings_to_price_ratio, book_to_price_ratio
   └── 风险类(反向): raw_beta(w=-2.0), residual_volatility(w=-1.5)
   └── 每行业选 Top-2 个股

7. 等权配置 + 10%单股上限 + 25%行业上限 + 大盘过滤系数 + 绝对动量系数
```

### 3.2 RRG 框架原理

**RRG（Relative Rotation Graph）** 是 2026 量化轮动策略报告提出的行业轮动框架：

```
RS = 行业均价 / 沪深300 close          # 相对强度比值
RS-Ratio = RS / SMA(RS, 220) × 100     # 长期标准化（>100 长期跑赢大盘）
RS-Momentum = RS-Ratio / RS-Ratio.shift(30) × 100  # 短期动量（>100 在加速）
```

四象限分类：
- **领先（RS-Ratio>100, RS-Mom>100）**: 长期跑赢+加速 → 优先选择
- **改善（RS-Ratio<100, RS-Mom>100）**: 长期跑输但加速 → 关注
- **滞后（RS-Ratio<100, RS-Mom<100）**: 长期跑输+减速 → 回避
- **疲软（RS-Ratio>100, RS-Mom<100）**: 长期跑赢但减速 → **预警转弱，剔除**

**核心价值**：RS-Momentum 是先行指标，能在行业绝对动量仍正但相对强度已转弱时提前发出预警。

### 3.3 RS-Momentum 窗口选择（30日 vs 60日）

研报推荐 60 日 RS-Momentum 窗口，但本策略改用 30 日，原因：

| RS-Mom 窗口 | 6/22 建筑材料 RS-Mom | 是否剔除 | OOS 总收益 | OOS 超额 |
|-------------|----------------------|----------|------------|----------|
| 60日（研报）| 108.33 | 否（>100）| -2.72% | +0.29% |
| **30日（本策略）** | **97.34** | **是（<100）** | **-1.51%** | **+1.50%** |

- 60日窗口反应过慢，无法识别建筑材料6月已转弱
- 30日窗口及时识别，将建筑材料替换为银行，避免7月下跌
- IS 表现也进一步提升（Sharpe 0.8006→0.9222, +15.2%）

### 3.4 研报参考

v9 迭代参考了以下2026年最新研报：

1. **2026 量化轮动策略报告（RRG 框架）**: RS-Ratio(220日)+RS-Momentum(60日)，第一象限领先行业
