## 1. 策略概述

### 1.1 核心思路

行业轮动策略：在强势行业中选强势个股，利用聚宽260因子做个股层多因子选股，并通过 多周期RRG相对强度动量+行业估值过滤+行业短期风险过滤+绝对动量+大盘趋势过滤 五重防御规避高风险板块。

- **行业层**: 60+120日动量排名选Top-5 → 多周期RRG投票(10/30/60日RS-Mom)重选领先象限 → 20日短期风险过滤 → 行业PE分位过滤
- **个股层**: 12因子加权z-score复合评分（含2个反向BARRA风险因子），每行业选Top-2个股
- **风控层**: 大盘趋势过滤（跌破20日均线空仓，跌破5日均线降仓50%）+ 绝对动量（20日收益<-3%降仓50%）+ regime_adaptive风控
- **调仓**: 周频调仓（每周一），cost_benefit调仓模型

### 1.2 v15 相对 v9 的改进

v15 在 v9 基础上完成两步迭代（v9 → v14 → v15），核心改进为 **多周期RRG投票** + **行业估值过滤**：

#### v14 改进：多周期 RRG 投票

1. **v9 单周期 RS-Mom 30日存在 data snooping 风险**：
   - v9 采用单一 30 日 RS-Mom 窗口（vs 研报推荐 60 日），参数选择依赖 OOS 验证
   - v9 IS Sharpe 0.4150 部分来自单周期过拟合，OOS 仅 0.0401

2. **v14 多周期投票降低单周期过拟合**：
   - 同时计算 10/30/60 日三个 RS-Mom 窗口
   - 行业入选需 ≥2 个窗口 RS-Mom ≥ 100（多数投票）
   - 多周期投票更稳健，避免单一周期参数选择带来的过拟合

3. **v14 OOS 显著提升**：
   - OOS Sharpe 从 0.0401 跃升至 1.7018（+4143%）
   - OOS 收益从 -0.02% 提升至 +3.32%（+3.34pp）
   - IS Sharpe 略降至 0.3277（-21%），证明 v9 单周期存在 IS 过拟合

#### v15 改进：行业 PE 分位过滤

1. **华商基金估值安全边际思路**：
   - 动量虚高的行业可能伴随估值泡沫
   - 用 earnings_to_price_ratio(=1/PE) 作为估值代理
   - E/P 历史分位 < 10%（即 PE 处于近250日 90% 分位以上）视为过贵，剔除

2. **v15 IS 表现回升**：
   - IS Sharpe 从 0.3277 提升至 0.4030（+23%）
   - IS 总收益从 +15.61% 提升至 +18.46%（+2.85pp）
   - OOS 持平（PE 过滤在 OOS 期间未触发，作为第二道防线）

3. **OOS 未触发原因**：
   - OOS 期间大盘跌破 20 日均线，market_filter 已将仓位降至 0%
   - market_filter + RRG 已识别并规避了估值过贵行业
   - PE 过滤作为"第二道防线"，在 market_filter/RRG 失效时才触发

### 1.3 选股流程

```
1. 大盘趋势过滤 (沪深300 5/20日均线)
   ├── 跌破20日均线 → 空仓 (scale=0.0)
   ├── 跌破5日均线 → 降仓50% (scale=0.5)
   └── 否则 → 满仓 (scale=1.0)

2. 绝对动量叠加 (Dual Momentum)
   └── 若 scale>0 且 沪深300 20日收益 < -3% → scale *= 0.5

3. 行业动量排名 (60日×0.6 + 120日×0.4)
   └── 选 Top-5 行业（候选）

4. RRG 多周期投票 (NEW in v14)
   ├── 计算每个行业的 10/30/60 日 RS-Mom
   ├── vote_count = (RS-Mom_10≥100) + (RS-Mom_30≥100) + (RS-Mom_60≥100)
   ├── 筛选 vote_count ≥ 2 的行业（多周期领先）
   └── 至少保留 3 个行业

5. 行业短期风险过滤 (20日动量)
   └── 剔除短期动量为负的行业，至少保留 3 个

6. 行业估值过滤 (NEW in v15, 华商基金思路)
   ├── 计算每个行业 E/P 在近 250 日的分位
   ├── 剔除 E/P 分位 < 10% 的行业（即 PE 历史最贵 10%）
   └── 至少保留 3 个行业

7. 个股多因子评分 (12因子加权z-score)
   ├── 动量类(正): Price1M, Price3M, ROC20
   ├── 成交量类(正): DAVOL10, money_flow_20
   ├── 质量类(正): gross_income_ratio, roe_ttm, net_profit_ratio
   ├── 价值类(正): earnings_to_price_ratio, book_to_price_ratio
   └── 风险类(反向): raw_beta(w=-2.0), residual_volatility(w=-1.5)
   └── 每行业选 Top-2 个股

8. 等权配置 + 10%单股上限 + 25%行业上限 + 大盘过滤系数 + 绝对动量系数
```

### 1.4 v9 OOS 局限性分析（v14/v15 改进动机）

v9 OOS 6/22 调仓选了 通信+电子+建筑材料+银行，7月表现：
- 建筑材料 30日 RS-Mom=97.34<100 被剔除（v9 改进点）
- 但 v9 单周期 30 日窗口依赖 OOS 验证选择，存在 data snooping 风险
- v9 OOS Sharpe 仅 0.0401，IS-OOS 一致性差

v14 多周期投票（10/30/60日）成功降低单周期过拟合：
- 不再依赖单一 30 日窗口的 OOS 表现
- 多周期投票更稳健，OOS Sharpe 跃升至 1.7018

v15 PE 过滤进一步提升 IS 表现：
- 在 v14 基础上加入估值维度
- IS Sharpe 从 0.3277 提升至 0.4030，恢复到接近 v9 水平
- OOS 持平，IS-OOS 一致性最优

### 3.2 多周期 RRG 投票原理

**多周期 RRG 投票**（v14 新增）是对 v9 单周期 RRG 框架的改进：

```
单周期 (v9):
  RS-Mom_30 = RS-Ratio / RS-Ratio.shift(30) × 100
  领先行业: RS-Mom_30 ≥ 100

多周期投票 (v14/v15):
  RS-Mom_10 = RS-Ratio / RS-Ratio.shift(10) × 100  # 短期
  RS-Mom_30 = RS-Ratio / RS-Ratio.shift(30) × 100  # 中期
  RS-Mom_60 = RS-Ratio / RS-Ratio.shift(60) × 100  # 长期
  vote_count = (RS-Mom_10≥100) + (RS-Mom_30≥100) + (RS-Mom_60≥100)
  领先行业: vote_count ≥ 2  # 多周期多数投票
```

**核心价值**：
- 单周期参数选择（如 v9 的 30 日）易过拟合到 OOS 数据
- 多周期投票降低单周期参数敏感性
- 10/30/60 日三窗口覆盖短/中/长周期，更稳健
- 多数投票（≥2）避免单周期噪声

### 3.3 行业 PE 分位过滤原理（v15 新增）

**华商基金估值安全边际思路**：

```
E/P = earnings_to_price_ratio = 1 / PE  # 高 E/P = 便宜
pe_percentile = mean(history_ep <= current_ep)  # 当前 E/P 在历史的分位

过滤规则:
  if pe_percentile < 0.10:  # E/P 历史最低 10%（即 PE 历史最高 90%）
      剔除该行业  # 估值过贵
  至少保留 3 个行业  # 避免全部被剔除
```

**核心价值**：
- 动量维度（RRG/abs_mom）+ 估值维度（PE 分位）正交，提供独立信号
- 规避"动量虚高+估值泡沫"行业（如 2015 年创业板）
- 作为 market_filter/RRG 失效时的第二道防线

### 3.4 研报参考

v15 迭代参考了以下研报与基金公司思路：

1. **2026 量化轮动策略报告（RRG 框架）**: RS-Ratio(220日)+RS-Momentum，第一象限领先行业
   - v14 改进：多周期投票(10/30/60日)替代单周期(30日)
2. **华商基金（估值安全边际）**: 行业轮动重视估值锚定
   - v15 应用：E/P 分位<10% 剔除估值过贵行业
3. **v9 稳健性分析建议**: 多周期 RRG 组合降低单周期过拟合
   - v14 实现：10/30/60 日三窗口投票
4. **Gary Antonacci 双动量**: 相对动量+绝对动量，v8 的 abs_mom 即源于此

### 7.2 失败的探索（lessons learned）

- **v10 残差动量 + 中证500池**: IS Sharpe 0.7666 最优但 OOS -7.08% 最差，中证500池过拟合
- **v11 拥挤度过滤**: 95% 分位阈值过严，频繁剔除表现好的行业
- **v12 ML40因子**: LightGBM 仍不超越等权线性，10/40 因子间非线性关系有限
- **v13 残差动量 + 沪深300池**: 与 v9 结果完全相同，残差动量在 beta 均匀池无效
- **v16 拥挤度动态分域反转**: 简单反转评分符号与原框架冲突，IS Sharpe 0.4030→0.1908

### 7.3 关键经验

1. **候选池选择易过拟合**: IS 显示中证500最优但 OOS 严重过拟合，沪深300 OOS 最稳定
2. **多周期投票降低单周期过拟合**: v14 多周期 RRG 投票 OOS Sharpe 从 0.04 跃升至 1.70
3. **估值维度与动量维度正交**: v15 PE 过滤提升 IS 不损 OOS，作为第二道防线
4. **ML 未超越等权线性**: 因子间非线性关系有限，20日收益标签噪声大
5. **拥挤度反转需独立反转因子**: 简单符号反转与原框架冲突，应使用 Reversal20 等独立因子
6. **残差动量非普适改进**: 仅在 beta 分散的池（中证500）有效，在 beta 均匀的池（沪深300）无效
